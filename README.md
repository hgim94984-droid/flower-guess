# 오늘의 꽃 조각 맞히기

라이브 방송에서 **시청자가 채팅으로 꽃 이름을 맞히는** 게임입니다.
꽃 그림이 퍼즐 조각으로 가려져 있고, 조각을 하나씩 걷어 가며 맞힙니다.

설치할 것이 없습니다. `index.html` 을 더블클릭하면 바로 열립니다.

---

## 하는 법

1. 꽃 그림이 번호 붙은 퍼즐 조각으로 가려져 있습니다
2. **한 칸 열기** 를 누르면 조각이 하나씩 걷힙니다 (가운데부터, 순서는 매번 다름)
3. 시청자가 "7번 열어 주세요" 하면 **그 조각을 직접 눌러도** 열립니다
4. 어려워하면 **힌트** — 한 번 누르면 글자 수(`○○ ○○`), 한 번 더 누르면 초성(`ㅂㅇ ㅈㅁ`)
5. **정답 공개** 를 누르면 조각이 다 걷히고 꽃 이름이 뜹니다
6. **다음 문제** 로 넘어갑니다

조각 수는 9칸 · 16칸 · 25칸 중에 고릅니다. 고른 값은 저장됩니다.

### 키보드

| 키 | 하는 일 |
|---|---|
| `스페이스` | 한 칸 열기 |
| `H` | 힌트 |
| `Enter` | 정답 공개 → 한 번 더 누르면 다음 문제 |
| `→` | 다음 문제 (공개 없이 건너뛰기) |
| `M` | 소리 켜기 / 끄기 |
| `N` | 나이트 모드 |
| `F` | 전체화면 |

정답이 뜬 직후 0.8초 동안은 다음 문제로 넘어가지 않습니다.
Enter 가 두 번 눌려 정답이 바로 사라지는 사고를 막기 위해서입니다.

## 꽃 목록

`flowers.js` 에 꽃 234종의 그림 파일과 이름이 들어 있습니다(카드뽑기 게임의 그림과 이름).
234종을 한 바퀴 다 낼 때까지 같은 꽃이 다시 나오지 않습니다.

- 이름을 고치려면 `flowers.js` 에서 해당 줄의 이름만 바꾸면 됩니다
- 문제에서 빼려면 그 줄을 지우면 됩니다
- 오늘 판매할 꽃만 내고 싶으면 그 꽃의 줄만 남기면 됩니다
